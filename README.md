# Benresa-Consulting

A fintech-grade corporate web experience and interactive operations prototype for **Benresa Consult Limited** (Business, Human Resources, and Tax Advisory).

## Overview

This project modernizes the corporate identity and advisory operations of Benresa Consult Limited into a modern, transparent, and trackable client operations experience.

### Key Capabilities
- **Verified Sourced Service Taxonomy**: Authentic capabilities covering HR Consulting, Talent Acquisition, Tax Management, Statutory Compliance, Outsourcing, Learning & Development, and Strategic Business Consulting.
- **Benresa Connect Prototype**: Interactive client workspace with deterministic readiness checks, milestone SLA tracking, document centers, and versioned proposal reviews.
- **Responsive Typography System**: Display headers set in **Manrope** (700 weight, 88px / 92.4px line-height in display hero) with high-density UI and body text in **Inter** (21.6px / 33.48px).
- **Dual-Theme Support**: Dark fintech theme and light corporate theme with automatic system preference detection and manual toggle.

## Tech Stack
- **Framework**: Next.js 15 (Turbopack) & React 19
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4 & Custom Tokens
- **Icons**: Lucide React
- **Animations**: Framer Motion
- **Exporting**: jsPDF
- **Testing**: Vitest

## Getting Started

```bash
# Install dependencies
npm install

# Run the local development server
npm run dev

# Run unit tests
npm test

# Build for production
npm run build
```
